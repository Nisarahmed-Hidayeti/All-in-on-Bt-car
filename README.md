# BTcar

An Arduino-based Bluetooth-controlled all-in-one car project.

BTcar is a DIY robotics project built using an Arduino Uno. The car is controlled wirelessly through Bluetooth and includes basic movement controls, lighting, and a horn system. The project is being developed with the goal of adding autonomous features in the future.

## Features

### Current Features
- Bluetooth wireless control using HC-05
- Forward, backward, left, and right movement
- Front and rear lights
- Horn system
- DC motor control using L298N motor driver

### Planned Features
- Obstacle avoidance
- Autonomous driving 
- Line-following mode (planned)
- Improved control interface
- Additional sensors and smart features (plabned)

## Hardware

| Component | Purpose |
|---|---|
| Arduino Uno | Main controller |
| HC-05 Bluetooth Module | Wireless communication |
| L298N Motor Driver | Motor control |
| DC Motors | Car movement |
| LEDs | Front and rear lighting |
| Buzzer | Horn system |
| Breadboard | Prototyping |

## Software

- Arduino IDE
- Arduino C/C++
- Bluetooth serial communication
